---
**Who This Is For**

This repository is for anyone who wants to learn Linux but feels intimidated by it.

No computer science degree required. No prior terminal experience required. Just curiosity and consistency.

I'm Tuhin — I studied jewellery design, worked in the luxury goods industry, and pivoted into DevSecOps and cloud security. I built this while learning Linux from scratch at Scaler Academy. Every concept is explained the way I wish someone had explained it to me — plain English, real examples, and honest notes about where I got confused.

If I can learn this coming from a jewellery studio, you can learn this coming from anywhere.

---
**The Big Picture**

Before diving in, here is how Linux fits into the DevSecOps world:

```text
Linux is the foundation of almost everything in tech.
                │
                ├── 90% of servers worldwide run Linux
                ├── Every major cloud platform (AWS, GCP, Azure) runs on Linux
                ├── Containers (Docker, Kubernetes) run on Linux
                └── Security tools are built for Linux environments
```

If DevSecOps is your goal — Linux is not optional.
It is the ground you stand on.
